# Enishi releases

Signed and notarised downloads of **Enishi** for Mac, a private notebook about the people in your life.

- **Download:** the latest version is on the [Releases](https://github.com/realbakari/enishi-releases/releases/latest) page, or from [bakarimustafa.com/enishi](https://bakarimustafa.com/enishi/).
- **Updates:** Enishi checks `appcast.xml` in this repository for new versions. On its second launch it asks whether to check automatically; **Enishi › Check for Updates…** always works. Every update is signed, and Enishi installs only updates signed with Enishi's key.

This repository holds only release downloads and the update feed.
